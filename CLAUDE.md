# Instruções para o Claude neste projeto

- Não gerar/editar código diretamente no projeto sem autorização explícita do usuário para aquela alteração específica. O usuário prefere escrever o código ele mesmo; quando pedir ajuda, responder com explicação conceitual, passos ou trechos ilustrativos fora dos arquivos do projeto, em vez de aplicar a mudança diretamente.
